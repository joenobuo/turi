# チヌ釣り三昧 〜磯の主を求めて〜

一人称視点のリアル調3D磯釣りゲーム。ブラウザだけで動作します。

## 遊び方

`index.html` をブラウザで開くだけ(単一ファイル、Three.jsはCDNから読み込み)。

- **長押し** … キャストパワーを溜めて、離すと投げる
- ウキが消し込む「!!」の瞬間に **クリック** … 合わせ(フッキング)
- ファイト中は **押す=リールを巻く / 離す=糸を送る**。テンションゲージが赤で破断、糸を送りすぎると魚に走られる
- ドラッグで視点移動。右上のボタンから **図鑑📖 / タックル🎣 / メニュー**

## 特徴

- Gerstner波シェーダの海面、時間帯(朝→昼→夕→夜)で変化する空と光
- 魚種40種(チヌ・キビレ・マダイ・タチウオ・ヒラメ・アオリイカ等34種+黄金チヌなど架空生物6種)
- 全魚種が断面スイープ+Canvasテクスチャによるプロシージャル3Dモデル
- 釣果図鑑(未捕獲はシルエット)、最大サイズ・捕獲数の記録
- 竿6・リール5・仕掛け6・エサ5のタックルカスタマイズとショップ経済
- セーブはlocalStorage、効果音はWebAudio合成

## 開発

```
src/00_species.js   魚種データ
src/01_fishmodel.js プロシージャル魚モデル
src/02_ocean.js     海・空・磯環境
src/03_tackle.js    タックルデータ
src/04_game.js      ゲームロジック
src/05_ui.js        UI
src/06_main.js      一人称統合・メインループ
```

`node build.js` で src/ と style.css を連結し `index.html` を生成します。
